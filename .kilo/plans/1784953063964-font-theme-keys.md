# Font Theme Keys for Tailwind

## Goal
Register the font CSS variables (already loaded by `src/lib/fonts.ts` and applied on `<body>`) as Tailwind `font-*` utility classes in `globals.css`.

## Affected Files (1)
- `src/app/(frontend)/globals.css`

## Changes

### Edit 1 — Add font-family theme keys inside `@theme {}` block
Insert after line 5 (`--font-sans: …;`):

```css
  --font-archivo-black: var(--font-archivo-black);
  --font-manrope: var(--font-manrope);
  --font-montserrat: var(--font-montserrat-bold), var(--font-montserrat-extrabold);
```

### Edit 2 — Set Manrope as default body font
Change the `body` rule:
```diff
-  @apply bg-stone-50 font-sans text-stone-900 antialiased;
+  @apply bg-stone-50 font-manrope text-stone-900 antialiased;
```

## Validation
- `npm run dev` starts without font-related build errors.
- Inspect `<body>` in browser devtools — computed font-family should be `var(--font-manrope)` (Manrope).
- Any component can now use `className="font-archivo-black"`, `font-manrope`, or `font-montserrat`.
